## Context

When looking for a secondhand car on Craigslist, Facebook Marketplace, or OfferUp, I always run into the same problem: scams and unclear history.

The goal of Honesty is to give buyers a clear and trustworthy view of work done on a car, especially work done outside of traditional shops that usually never appears in a VIN report.

## Problem

Most tools either:

- focus only on official shop history,
- hide details behind paywalls,
- or optimize for auctions instead of transparent private-party sales.

## Solution

Honesty is a clean, mobile-first service history profile for each vehicle.

- Repair and modification timeline
- OEM part links and receipts
- Cost breakdowns
- Rich photo documentation

## Design Notes

I designed the interface to feel approachable for non-technical buyers while still providing the detail enthusiasts want.
