### This is the code for my personal portfolio, www.lucadenhez.com

Here you can view my various engineering projects along with fun explorations and case studies. I also love front-end web development, so this is a fun way for me to build my skills and tailor my blog posts to my liking.


#### Your project is a complete mess! Why?
This site is a showcase of my Next.js learning over the past year, so it's somewhat messily organized and for the most part *is not* in TypeScript. **(I will add types soon!)**


#### Flow
I wanted a way to as easily as possible write and upload my blog posts, so I am using **MDX**, which allows me to write my articles in Markdown and inject custom JSX components where I want. Each article has an `<ArticleHeader />` and `<CandidGallery />` to show project info and the teammates involved, followed by Markdown.

#### The main packages and frameworks used are:

- Next.js
- Tailwind
- Motion
- MDX
- Rehype
- Lenis
- React Photo Album
