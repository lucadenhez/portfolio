### This is the code for my personal portfolio at www.lucadenhez.com

This site is a showcase of my Next.js learning over the past year, so it's somewhat messily organized and for the most part is not in TypeScript! (I will add types soon...)

I wanted a way to as easily as possible write and upload my blog posts, so I am using MDX, which allows me to write my articles in Markdown and inject custom JSX components where I want. Each article has an <ArticleHeader /> and <CandidGallery /> to show project info and the teammates involved, followed by MD.

The main packages and frameworks used are:

- Next.js
- Tailwind
- Motion
- MDX
- Rehype
- Lenis
- React Photo Album
